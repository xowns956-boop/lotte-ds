AI로 설치하기 업데이트 현황

    Button

    hover·focus·pressed 칸은 상태 클래스(.k-state-*)로 고정해서 보여 준다. 실제 버튼은 마우스·키보드로 눌러 봐도 된다.

    Input

    focus 칸은 상태 클래스(.k-state-focused)로 고정해서 보여 준다. 실제 칸을 눌러 입력해 봐도 된다. 폭은 미리보기에서만 정한 값이다.

    TextArea

    focus 칸은 상태 클래스(.k-state-focused)로 고정해서 보여 준다. 실제 칸을 눌러 여러 줄 입력해 봐도 된다. 폭은 미리보기에서만 정한 값이다.

    Numeric

    PC 숫자 입력. 상자 모양·상태는 Input과 같다. 오른쪽 위·아래 칸을 눌러 값을 바꿔 볼 수 있다.

    Numeric Stepper

    태블릿 숫자 입력. 빼기·더하기 버튼을 눌러 값을 바꿔 볼 수 있다(단계 0.1).

    CheckBox

    focus 칸은 상태 클래스로 고정. 실제 상자를 눌러 봐도 된다. 크기 PC 16 · Tablet 24.

    RadioButton

    focus 칸은 상태 클래스로 고정. 고르면 가운데 점 8. 크기 PC 16 · Tablet 24.

    Switch

    눌러서 켜고 끌 수 있다. 트랙 PC 32×18 · Tablet 52×26.

    Label

    입력칸 이름. 필수 항목은 앞에 빨간 점.

    Badge

    상태·종류 표시. 글자 PC 12 · Tablet 14.

    Chip

    적용된 조회 조건. X는 조건 해제 버튼(지우는 동작은 화면 몫).

    Separator

    구역을 나누는 선. 가로는 폭을, 세로는 줄 높이를 채운다.

    DropDownList

    눌러서 목록을 열고 고를 수 있다(키보드: ↓↑ Enter Esc). focus·invalid 칸은 상태로 고정.

    Tooltip

    버튼에 마우스를 올리거나 Tab으로 가 보면 말풍선이 나온다. 아래 표는 모양만 고정해 보여 준 것.

    Loader

    불러오는 중. 1초에 한 바퀴. 색은 둘레 글자색.

    Skeleton

    불러오는 동안의 자리. 2초 주기로 흐려졌다 진해짐.

    Grid

    표 상자 · 머리줄 · 줄. 두 번째 줄은 마우스 올림, 세 번째 줄은 고른 줄로 고정. 줄 높이 PC 36 · Tablet 56.

    Tabs

    기본 = 밑줄형, 알약형 = ux-tabstrip-pill. 위 두 줄은 눌러서 바꿔 볼 수 있다(키보드 ← →). 아래 표는 상태를 고정해 보여 준다.

    Pager

    이전 · 페이지 번호 · … · 다음. 현재 페이지는 테두리. 아래 줄은 마우스 올림을 고정해 보여 준다.

    Dialog

    버튼을 누르면 실제 팝업이 열린다(Esc · 취소 · × · 뒤 가림으로 닫기, Alert는 뒤 가림으로 안 닫힘). 아래는 모양만 펼쳐 보인 것.

    Toast · Inline

    버튼을 누르면 실제 Toast가 오른쪽 아래에 4초 동안 뜬다. 아래는 모양만 펼쳐 보인 것.

    Form

    항목 = 라벨 · 입력칸 · 도움말 · 오류 문구(간격 8). 폼은 항목을 32 간격으로 쌓고 마지막에 버튼. 아래 표는 입력칸 종류 4 × 기본·오류.

    Card

    Card = 머리 · 내용 · 아래 버튼(필요 없는 줄은 뺌). Card / Stat = 지표 카드, trend 오름·내림 × tone 기본·강조.

    Avatar

    사람·서비스 표시. 이니셜(fallback) · 사진(image), 32 동그라미.

    Drawer

    사이드바. 왼쪽 위 버튼으로 펼침 256 ↔ 아이콘 모드 64(아이콘 모드에서는 마우스를 올리면 이름 말풍선). "생산"을 누르면 하위 메뉴가 닫히고 열린다. 아래 표는 상태를 고정해 보여 준다.

    Breadcrumb

    지금 화면의 위치를 보여 주는 경로 줄. 상위 단계는 흐린 링크(마우스를 올리면 진하게), 마지막은 현재 화면. 단계가 많으면 중간을 …으로 줄인다.

    Calendar · DatePicker

    날짜 고르기. 달력은 ‹ ›로 달을 넘기고, 날짜를 누르거나 키보드 화살표·Enter로 고른다. DatePicker는 칸을 누르면 달력이 뜨고, 고르면 닫힌다. 미리보기의 오늘은 2026-09-18로 고정.

    Toggle

    누를 때마다 켜짐·꺼짐이 바뀌는 버튼. 줄마다 꺼짐 · 마우스 올림 · 켜짐 · 켜짐+마우스 올림 · 비활성 · 켜짐+비활성. 첫 칸은 눌러서 바꿔 볼 수 있다.

    ButtonGroup · ButtonGroup / Toggle

    ButtonGroup은 붙어 있는 실행 버튼 묶음(누르면 바로 실행). ButtonGroup / Toggle은 고른 칸이 켜진 채로 남는 묶음 — 눌러서 바꿔 볼 수 있다(위 두 줄은 하나만, 마지막 줄은 여러 개).

    Menu

    버튼을 누르면 뜨는 동작 목록. "더보기"를 눌러 마우스·키보드(↓ ↑ → ← Enter Esc)로 써 볼 수 있다. 아래는 상태를 고정해 펼쳐 둔 것.

    TreeView

    펼치고 접는 계층 목록. 왼쪽 트리는 눌러서·키보드(↓ ↑ → ← Enter)로 써 볼 수 있다. 오른쪽은 단계 × 펼침 × 선택 상태를 고정해 둔 것.

    Stepper

    여러 단계로 나뉜 등록·설정 흐름에서 지금 어느 단계인지 보여 준다(누를 수 없음). horizontal = 폼 위, vertical = 왼쪽 목록형.

    ProgressBar

    얼마나 진행됐는지 보여 주는 막대. 값 0 · 25 · 50 · 75 · 100 (폭 320 예시, 실제로는 놓이는 자리를 채움).

    ExpansionPanel

    제목 줄을 눌러 내용을 접었다 폈다 하는 패널. 조회 조건 영역에 쓴다. 눌러서 바꿔 볼 수 있다(폭 480 예시).

    Splitter

    위아래 칸 사이 막대를 끌거나, 막대에 포커스를 두고 ↑ ↓ · Home · End로 위 칸 높이를 바꾼다.

    Toolbar

    버튼·구분선을 한 줄로 묶는 도구 모음. 안의 버튼은 sm, 주 동작 1개만 primary.

    Kbd

    단축키 안내용 키 표시. 키 하나는 Kbd, 여러 키 조합은 KbdGroup. 눌리는 단추가 아니다.

    PageTab

    화면 맨 아래에 열린 화면을 탭으로 보여 주는 줄. 위 줄은 상태 3개(default · hover · active), 아래 줄은 눌러서 바꿔 볼 수 있다. X는 close 이벤트만 보낸다.

    AppBar

    화면 맨 위 머리줄(패턴). 메뉴 토글 · 이 화면 즐겨찾기 ☆ · 화면 제목 + 작은 경로 · 검색(InputGroup) · 즐겨찾기 목록 · 사용자. ☆는 눌러 볼 수 있다. 둘째 줄은 빼도 되는 칸을 뺀 모양.

    PageHeading

    본문 맨 위 제목 영역(패턴). 제목 · 설명 · 오른쪽 버튼 최대 2개(보조 outline · 주요 primary). 아래 줄은 설명·버튼을 뺀 모양.

    Toolbar / Filter

    표 위에 붙이는 조회 조건 한 줄(패턴). 검색 · 필터 2개 · 날짜 · 초기화. 필터·날짜는 눌러서 써 볼 수 있다.

    Toolbar / Form Action

    등록·수정 화면 맨 아래에 붙는 버튼 줄(패턴). 오른쪽 [취소] [저장]. 실제 화면에서는 아래에 붙어 있고, 여기서는 자리에 둔다.

    Form Table

    이름 + 값 입력 표(패턴). 모달이나 본문에서 쓴다. 위 표는 기본(4줄 × 읽기 칸 2개), 아래 표는 입력 부품·쌓기·한 칸 줄 예시(폭 552).

    Dialog Content

    팝업 내용 칸에 끼우는 6가지(패턴). 폭 550 예시. Option Buttons를 쓸 때는 팝업 아래 버튼 줄을 뺀다.

    Menu Tile

    태블릿 메인 메뉴 타일. 상태 default · pressed(누르는 동안), 긴 이름은 두 줄, 아이콘은 빼도 된다(폭 324 예시).

    SectionCards

    지표 카드(Card / Stat) 한 줄(패턴). 같은 폭 · 간격 16, 기본 4개. 폭이 좁으면 카드가 같이 좁아진다(본문 1440 = 카드 348).

    색

    라이트·다크 버튼으로 바꿔 보면 같은 이름의 값이 바뀐다.

    기기 (PC · Tablet)

    PC·Tablet 버튼으로 바꿔 보면 높이·글자 크기가 바뀐다.
